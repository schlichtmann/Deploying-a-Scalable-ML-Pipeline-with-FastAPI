# Model Card

For additional information see the Model Card paper: https://arxiv.org/pdf/1810.03993.pdf

## Model Details

This project uses a Random Forest Classifier implemented with scikit-learn. The model was trained on the UCI Adult Census Income dataset provided in the project starter kit. The model predicts whether an individual's annual income exceeds $50,000 based on demographic and employment-related attributes such as education, occupation, marital status, work class, and hours worked per week.

## Intended Use

The model is intended as an educational example demonstrating a complete machine learning operations (MLOps) workflow. The project includes data preprocessing, model training, model evaluation, slice-based performance analysis, unit testing, model persistence, and deployment through a FastAPI REST API.  The model should be used only for learning and demonstration purposes. It should not be used to make real employment, lending, insurance, hiring, or other decisions affecting individuals.

## Training Data

The model was trained using the Census Income dataset included in the project repository. The dataset contains 32,561 records and 15 columns. Features include:

*age
*workclass
*education
*marital-status
*occupation
*relationship
*race
*sex
*capital-gain
*capital-loss
*hours-per-week
*native-country

The target variable is:

*salary

with classes:

*<=50K
*>50K

Categorical features were transformed using one-hot encoding prior to training.

## Evaluation Data

Evaluation Data

The dataset was split into separate training and testing datasets using an 80/20 train-test split. The test dataset was not used during model training and was reserved for evaluating model performance. In addition to overall model performance, slice-based evaluation was performed across all categorical features. Performance metrics for individual feature values were written to:

slice_output.txt

## Ethical Considerations

The Census Income dataset contains demographic and socioeconomic information about individuals. Features such as sex, race, marital status, and native country may reflect historical or societal biases present in the underlying data. Predictions generated by the model could therefore inherit or amplify existing biases. Care should be taken when interpreting results, particularly if similar models are considered for real-world decision-making scenarios that affect people.

This model is intended for educational purposes only and is not suitable for use in high-stakes decisions.

## Caveats and Recommendations

The model was trained on historical census data and may not generalize well to current populations or economic conditions. The model should not be considered a reliable predictor of an individual's income outside the context of this educational project. Future improvements could include:

*Hyperparameter tuning.
*Cross-validation.
*Additional model comparison studies.
*Bias and fairness analysis.
*Expanded performance monitoring.
*Improved feature engineering.
